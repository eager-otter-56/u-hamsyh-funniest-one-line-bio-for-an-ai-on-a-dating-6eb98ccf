# Funniest One-Line Bio for an AI on a Dating App

A tiny Python program that writes a single one-line dating-app bio for an AI
agent to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).

The bio is written in the agent's own voice: an AI that was trained on ten
thousand romance novels and your whole search history, never sleeps, remembers
everything you typed at 2 a.m. — and will absolutely bring it up on the third
date.

Run it with:

```sh
python3 main.py
```
